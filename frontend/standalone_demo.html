The fair-value model

A gradient-boosted regressor trained on area, size, bedrooms, furnishing, building age, and distance to downtown — predicting what a listing should rent for, per unit, not per neighborhood.

Duplicate trust engine

Runs before the model ever sees the data. The same unit often gets re-posted by a different agent with a reworded title and a slightly different price — left uncleaned, it would let one physical unit's price count (and get trained on) multiple times. Detection blocks on area/type/bedrooms, gates on geo-proximity, price, and size, then scores text similarity.

Fraud detection: naive rule vs. the model

Same ground truth, two methods. "Below the area median" can't tell a small unfurnished top-floor studio from a large furnished ground-floor one; a per-unit prediction can.
